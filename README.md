# Домашнє завдання №4 — JavaScript

Три незалежні задачі на роботу з об’єктами.

- `js/task-1.js` — `isEnoughCapacity(products, containerSize)`: підрахунок кількості товарів і перевірка місткості контейнера.
- `js/task-2.js` — `calcAverageCalories(days)`: середня кількість калорій; для порожнього масиву повертає `0`.
- `js/task-3.js` — `profile`: зміна імені, збільшення ігрового часу та отримання інформації через методи з `this`.

## Перевірка

Відкрийте `index.html` та консоль браузера (DevTools → Console).
У файлах залишено всі перевірочні виклики з умови завдання.

Очікувані результати:

```text
true
false
true
false
3180
2270
0
Jacob has 300 active hours!
Marco has 300 active hours!
Marco has 320 active hours!
```

Код відформатовано Prettier. Перевірка форматування:

```sh
npx prettier --check .
```
